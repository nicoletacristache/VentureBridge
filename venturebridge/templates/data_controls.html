LLM API

哪些内容会发送给模型服务

仅在生成画像、推荐、事件叙事、反馈或过程证据编码时，发送完成当前任务所需的最小化内容。应用不会把 API 密钥、访问码或内部数据库标识放入提示词。

  • 画像阶段：去标识化的背景与经历文本，以及结构化偏好字段
  • 事件阶段：必要的画像摘要、当前可见状态、历史决策摘要和受控蓝图
  • 反馈阶段：本次事件内容与学习者主动提交的回答

实际 API 供应商及其数据处理规则由部署者配置。使用前应由教学机构完成相应的数据保护审查。
