LLM API

What Content Is Sent to Model Services

Only minimal content necessary to complete the current task is sent when generating profiles, recommendations, event narratives, feedback, or process evidence coding. The application does not include API keys, access codes, or internal database identifiers in prompts.

  • Profile Phase: De-identified background and experience text, plus structured preference fields
  • Event Phase: Necessary profile summaries, current visible state, historical decision summaries, and controlled blueprints
  • Feedback Phase: Current event content and responses actively submitted by the learner

Actual API providers and their data processing rules are configured by the deployer. A corresponding data protection review should be completed by the educational institution prior to use.

Your Control Rights

  1. 1
    View

    Trace profile evidence, recommendation rationale, and event history.

  2. 2
    Correct

    Create new profile versions to correct LLM misinterpretations or outdated information.

  3. 3
    Delete

    Delete the learning space and its associated records.

Avoid Secondary Exposure

Do not forward page screenshots to unrelated personnel when viewing history. If you find submitted content contains identity information, correct or delete it first.

Dangerous Action

Delete Entire Learning Space

This operation will delete profiles, recommendations, simulations, responses, and their associated records, and exit the current session. Local data after deletion cannot be recovered through this system; independent security logs that the deployer is legally required to retain are not covered by this commitment and should follow institutional guidelines.
