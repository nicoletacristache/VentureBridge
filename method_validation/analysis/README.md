# Analysis Code

`run_measurement_validation.py` implements nine measurement methods. `score_ecd_audit.py` implements rule and structured LLM encoders. `evaluate_ecd_audit.py` evaluates their saved predictions. Install `requirements_measurement_validation.txt` alongside the application requirements.

See [the method guide](../README.md) for commands and [the central provenance note](../PROVENANCE.md) for source and scope.
